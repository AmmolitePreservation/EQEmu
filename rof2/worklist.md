# RoF2-only worklist

Status tags: `done`, `fix` (to build), `owner` (the owner's call), `peridotTest`. RC-1 to RC-10 are `done`; the open items are the account-wide state that several sessions of one account share (RC-11 to RC-13), and Peridot takes RC-10 only with them. README.md's "Deploying to Peridot" lists the deploy steps.

## Owner decisions

- **One client (2026-11-01):** every client but Rain of Fear 2 goes; `guids` is rebased onto this branch and drops `trader.item_sn` there; player housing follows `guids`; bots are rewritten after housing.
- **Database columns (2026-11-01):** look for columns the removed clients made necessary and bring them with evidence, no guesses.
- **Three axes (2026-11-01):** the client version is neither the era the server emulates (`Expansion:CurrentExpansion`, min and max expansion, content flags) nor the zone version (`version`). With one client the client axis carries no information, so it goes from content, code and the quest API; what ProjectEQ expressed on it moves to the axis it belongs to.
- **Future content imports (2026-11-01):** out of scope. The content tables are ours to shape; a later ProjectEQ import is handled when it happens.
- **Zone lines follow the era (2026-11-02):** where ProjectEQ kept two rows for two client generations, the pair stays and the era columns choose; what the client can load is the client package's concern. Only rows that differ in nothing but a client file index go.
- **Era behaviour in code goes on rules (2026-11-02):** EQEmu already configures the era with server rules (`Expansion:CurrentExpansion`, `World:ExpansionSettings`); code that collapsed a client test should key on those or derive from served data, not grow new columns.
- **Migrations (2026-11-01):** in EQEmu's normal manifest; `rof2` starts at 9326, where guids started, and guids is renumbered after the rebase.
- **One account per player (2026-11-12):** Ammolite's name and password is the only login; one account holds all of a player's characters (the owner's 72 on Peridot among them), and the largest raid plus two groups, 72 + 12 = 84, are logged in from it at once. Peridot gets it before `guids` and housing finish, so the work is on `rof2`.
